## 5 本轮修复的缺陷（6 项，均已复测）

| # | 缺陷 | 原因 | 改法 | 验证 |

| 1 | 切页后内容错乱：network 卡在「加载中…」、logs 里显示网卡表 | `go()` 异步渲染无取消机制，旧页晚到的结果覆盖新页 | 每次渲染挂到**私有容器**，旧页面写进已脱离节点 | 14 页全部正确渲染 |

| 5 | `/api/network/ifaces`、`is_admin` 每次起 PowerShell（3–4 秒） | 每次调用都探系统 | `is_admin` 缓存 60s、网卡枚举缓存 5s | 冷 4.04s → 热 **0.01s** |

## 6 仍然存在的限制（上线前必读）

1. **必须管理员权限**：改 IP（返回 `ELEVATION_REQUIRED`）、读 Windows 安全日志、防火墙封禁/主机隔离。非管理员下这些是「如实失败 + 记审计」，不是 bug。
2. **打包未验证**：PyInstaller 未安装，便携 exe 打包链路还没跑过。
3. ~~**前端仍是单文件 + 内联事件**~~ **已闭环（2026-11-07）**：S-01 转义、事件委托+严格 CSP、虚拟滚动+游标分页三项改造全部完成并经 e2e ALL PASS（阻断项①②③）。当前 index.html 为虚拟滚动版：51 处内联事件改 `data-act`+委托、CSP 用 `script-src 'nonce-bg2026'`、日志/审计游标分页渲染。
4. ~~**令牌存 localStorage**~~ **已闭环（2026-11-07）**：令牌改 HttpOnly Cookie（`bg_token`，SameSite=Lax），前端不再持有明文令牌、localStorage 无 `bg_token` 残留，e2e 令牌断言双 True。
5. **多实例**：每个实例启动都写 `port.txt`，本次验收就发现 2 个残留进程。启动前先确认没有旧实例（或改成固定端口）。

## 7 复现方法

```powershell
cd "D:\Work\BlueGuard"
python -m backend.app                                  # 起服务（端口见 backend\data\port.txt）
python backend\_selftest_core.py                       # 核心单测：建表/检索/审计链/篡改检测
python backend\_selftest_platform.py                   # 平台适配层：网卡/快照/三级验证/补扫
python "D:\Work\e2e.py"                 # UI 14 页 + 交互（需 Python311，带 websocket）
```

**API 端到端要跑在干净库上**（`_selftest_api.py` 里断言了 `total=1` 这类空库前提，重复跑会因资产重名在「创建资产」处失败——这是测试不幂等，不是功能问题）。干净库跑法：

```powershell
$env:BLUEGUARD_DATA="$env:TEMP\bg_selftest"
python -m backend.app          # 另开一个窗口；这个实例的数据落在 %TEMP%\bg_selftest
python backend\_selftest_api.py
```

`_selftest_api.py` / `_selftest_ui.py` 已改为自动读端口（跟随 `BLUEGUARD_DATA`），不再有硬编码端口；UI 脚本也改成只结束自己拉起的 headless Edge，不会误杀你正在用的浏览器。
